# Daily desk metrics

- Open `PORT` or `POS`, expand **Holdings risk · daily archive**, and select **Load / refresh risk**. Each holding shows close versus SMA50, RSI14 (OB ≥70, OS ≤30), and concentration. The concentration threshold defaults to 20% and can be changed in the pane. Weights use absolute broker-reported position values divided by gross holdings value in the same currency and selected account scope. Missing valuations make that currency's weights unavailable. Archive dates appear beside the chips; these are daily closes, not live quotes.
- In `SCAN`, the sort picker includes **ADMA Stretch / SMA50 ATR14**, **ADMA Stretch / SMA50 %**, and **SPY relative 63d %**. The three corresponding columns are always shown. Signed stretch is `(close − SMA50) / Wilder ATR14` and `(close / SMA50 − 1) × 100`; ascending finds compressed names, descending finds extended names. This requested SMA50 measure differs from Whats-News' adaptive ADMA average. Existing setup and stale-data filters still apply.
- On a daily chart, open the chart context menu and enable **Daily RS / SPY (100 at first common date)**. The line is `(close / SPY close) / first_common_ratio × 100`, scaled to the price axis for display; the legend reports its normalized value. Missing SPY dates remain blank. The scanner reports the ratio's percent change over 63 symbol sessions, requiring SPY at both endpoints. SPY must already be available in the scanner archive; absent history shows an em dash.

These features reuse the existing daily archive/provider reads and SMA, RSI, and Wilder ATR calculations. They add no endpoints or journal writes. Risk history and chart toggles are session state.
